# TagRigger 🏷️

**Professional Tag Management for Creators and Marketers**

TagRigger is a lightweight, powerful Windows desktop application designed to help you organize, filter, and manage your hashtags with ease. Build custom tag sets, utilize smart randomization, and streamline your social media workflow directly from your desktop.

🌐 **Official Website:** [tagrigger.com](https://tagrigger.com)  
🛍️ **Microsoft Store:** *Coming Soon*

## About This Repository

This repository hosts the HTML and CSS source code for the official TagRigger landing pages and website. 

*Note: The core TagRigger application is a commercial desktop product and its source code is not public. You will soon be able to download the compiled application directly from the Microsoft Store.*
